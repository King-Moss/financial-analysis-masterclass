# 📊 Financial Analysis Masterclass with Python

Welcome to this mini-masterclass on **Stock Return Analysis** using Python! This project guides you through calculating and visualizing **log returns** and **cumulative returns** of multiple stocks over a five-year period using real-time data from Yahoo Finance.

## 🚀 What You’ll Learn

- How to pull historical stock data using `yfinance`
- How to compute daily **log returns**
- How to calculate **cumulative returns**
- How to visualize investment performance using **Matplotlib**

## 🧰 Tools and Libraries

- Python 3.7+
- pandas
- numpy
- matplotlib
- yfinance
- pandas_datareader

## 📁 Project Structure

```
financial-analysis-masterclass/
│
├── images/                   # Saved plots
├── src/                      # Source code
│   └── analysis.py           # Main script for data analysis
├── README.md                 # This file
├── requirements.txt          # Libraries to install
└── .gitignore                # Files to ignore in version control
```

## 💻 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/financial-analysis-masterclass.git
cd financial-analysis-masterclass
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Run the script

```bash
python src/analysis.py
```

## 📈 Sample Output

The script will generate a chart of cumulative returns and save it as `images/cumulative_returns.png`.
